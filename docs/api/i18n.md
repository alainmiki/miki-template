# i18n API

## registerTranslation

Register translations for a language.

```javascript
const { registerTranslation } = require('miki-template');

registerTranslation('en', {
  hello: 'Hello',
  goodbye: 'Goodbye'
});
```

## unregisterTranslation

Unregister translations.

```javascript
const { unregisterTranslation } = require('miki-template');

// Unregister a specific key
unregisterTranslation('en', 'hello');

// Unregister entire language
unregisterTranslation('en');

// Unregister all translations
unregisterTranslation();
```

## setLanguage / getLanguage

Set or get the active language.

```javascript
const { setLanguage, getLanguage } = require('miki-template');

setLanguage('fr');
console.log(getLanguage()); // 'fr'
```

## setFallbackLanguage / getFallbackLanguage

Set or get the fallback language.

```javascript
const { setFallbackLanguage, getFallbackLanguage } = require('miki-template');

setFallbackLanguage('en');
console.log(getFallbackLanguage()); // 'en'
```

## getAvailableLanguages

List all registered languages.

```javascript
const { getAvailableLanguages } = require('miki-template');

console.log(getAvailableLanguages());
// ['en', 'fr', 'es']
```
