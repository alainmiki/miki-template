# i18n API



## registerTranslation



Register translations for a language. Keys match the `{% trans "text" %}` source string.



=== "CommonJS"



    ```javascript

    const { registerTranslation } = require('miki-template');



    registerTranslation('en', {

      hello: 'Hello',

      goodbye: 'Goodbye'

    });

    ```



=== "ES Modules"



    ```javascript

    import { registerTranslation } from 'miki-template';



    registerTranslation('en', {

      hello: 'Hello',

      goodbye: 'Goodbye'

    });

    ```



You can also register nested keys for `blocktrans` with variables:



=== "CommonJS"



    ```javascript

    const { registerTranslation, setLanguage } = require('miki-template');



    setLanguage('en');

    registerTranslation('en', {

      'Welcome, {name}!': 'Welcome, {name}!',

      'Goodbye, {name}!': 'Goodbye, {name}!'

    });

    ```



=== "ES Modules"



    ```javascript

    import { registerTranslation, setLanguage } from 'miki-template';



    setLanguage('en');

    registerTranslation('en', {

      'Welcome, {name}!': 'Welcome, {name}!',

      'Goodbye, {name}!': 'Goodbye, {name}!'

    });

    ```



## unregisterTranslation



=== "CommonJS"



    ```javascript

    const { unregisterTranslation } = require('miki-template');



    // Unregister a specific key

    unregisterTranslation('en', 'hello');



    // Unregister entire language

    unregisterTranslation('en');



    // Unregister all translations

    unregisterTranslation();

    ```



=== "ES Modules"



    ```javascript

    import { unregisterTranslation } from 'miki-template';



    unregisterTranslation('en', 'hello');

    ```



## setLanguage / getLanguage



Set or get the active language.



=== "CommonJS"



    ```javascript

    const { setLanguage, getLanguage } = require('miki-template');



    setLanguage('fr');

    console.log(getLanguage()); // 'fr'

    ```



=== "ES Modules"



    ```javascript

    import { setLanguage, getLanguage } from 'miki-template';



    setLanguage('fr');

    console.log(getLanguage()); // 'fr'

    ```



## setFallbackLanguage / getFallbackLanguage



Set or get the fallback language (used when a key is missing from the active language).



=== "CommonJS"



    ```javascript

    const { setFallbackLanguage, getFallbackLanguage } = require('miki-template');



    setFallbackLanguage('en');

    console.log(getFallbackLanguage()); // 'en'

    ```



=== "ES Modules"



    ```javascript

    import { setFallbackLanguage, getFallbackLanguage } from 'miki-template';



    setFallbackLanguage('en');

    ```



## getAvailableLanguages



List all registered languages.



=== "CommonJS"



    ```javascript

    const { getAvailableLanguages } = require('miki-template');



    console.log(getAvailableLanguages());

    // ['en', 'fr', 'es']

    ```



=== "ES Modules"



    ```javascript

    import { getAvailableLanguages } from 'miki-template';



    console.log(getAvailableLanguages());

    ```



## Template Tags



The `{% trans %}` and `{% blocktrans %}` tags are provided by the auto-activated `i18n` library:



```html

{% trans "Hello" %}

{% blocktrans %}Welcome, {{ name }}!{% endblocktrans %}

{% language "fr" %}...{% endlanguage %}

```
